ArcGraph Explorer moved to the packaged workbench

This file is a compatibility note for the old source-checkout viewer. The canonical ArcGraph Explorer template now lives in the Python package assets and is generated together with its graph and status payloads.

arcgraph visual workbench --output-dir output/arcgraph/reports/workbench

Then open output/arcgraph/reports/workbench/index.html through a local file server.
